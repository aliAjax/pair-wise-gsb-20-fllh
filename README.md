# hxwl-06 玻片柜位台账

显微镜玻片的柜位台账：入库登记、格位占用、借还跟踪、柜温冻结与样本查询。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- **入库登记**：登记样本、柜号、格位、保存温度；一个格位只放一张片
- **候补筐**：新片登记后先留在候补筐，分配格位后才入柜
- **借出/归还**：借出时登记观察者和预计归还时间，逾期未还在柜位图上标红
- **柜温冻结**：柜温超出保存范围自动冻结对应柜子，问题解决（温度恢复并解除冻结）前不能继续入柜
- **样本查询**：按样本名/染色方式查当前位置和完整取放记录
- **本机留档**：台账保存在 localStorage，重开页面数据不丢

## 代码分层（资料 / 占用判断 / 本机留档分开）

- `src/ledger/types.ts` —— 资料层：柜子、玻片、借还单、取放记录的数据结构
- `src/ledger/occupancy.ts` —— 占用判断：一格一片、温度范围、逾期、能否入柜等纯函数
- `src/ledger/storage.ts` —— 本机留档：localStorage 读写
- `src/ledger/seed.ts` —— 初始示例数据
- `src/ledger/reducer.ts` —— 台账状态流转（每个动作追加取放记录）
- `src/ledger/format.ts` —— 时间格式化
- `src/App.tsx` —— 页面：柜位图、候补筐、借还弹窗、柜温记录、样本查询
