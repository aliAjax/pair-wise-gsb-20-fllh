# hxwl-06 显微镜玻片柜位台账

玻片入库登记、柜位占用、借还跟踪、超温冻结与本机留档的柜位台账页。

## 技术栈

React + Vite + TypeScript + CSS（localStorage 本机留档）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

- **入库登记**：样本、柜号、格位、保存温度一次登记；一个格位只放一张片，已占用格位不可重复选择
- **候补筐**：新片先留在候补筐，分配空格位后才能入柜
- **借出 / 归还**：借出写明观察者与预计归还时间，逾期玻片在柜位图上闪烁标出，原格位保留至归还
- **温度冻结**：柜温超出柜内样本保存温度范围时自动冻结对应柜子，问题解决前不能继续入柜；温度恢复后自动解冻
- **样本检索**：重开页面后仍可按样本名称查当前位置与完整取放记录（登记候补 / 入库 / 借出 / 归还 / 冻结 / 解冻）

## 分层结构

- `src/data/` — 资料：领域类型与初始台账（`types.ts`、`seed.ts`）
- `src/logic/` — 占用判断：格位占用、空闲格位、逾期判断、温度冻结等纯函数（`occupancy.ts`）
- `src/storage/` — 本机留档：localStorage 读写（`local.ts`），与业务逻辑、界面解耦
- `src/components/` — 柜位图与样本检索界面组件
